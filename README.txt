SOMEBOYZ MEDIA WEBSITE
======================

HOW TO RUN
1. Extract SomeboyZ_Media_Project.zip.
2. Open the extracted SomeboyZ_Media folder in Visual Studio Code.
3. Install the "Live Server" extension (recommended).
4. Right-click index.html and choose "Open with Live Server".
   Or double-click index.html to open it in your browser.

PAGES
- index.html      Home
- about.html      About the studio
- services.html   Services
- gallery.html    Portfolio / mood gallery
- careers.html    Vacancies and talent registration
- contact.html    Contact and enquiry form

CUSTOMIZATION
- Edit text in the HTML files.
- Change colors and layout in style.css. Main red accent is --red.
- Replace gallery images with your own studio photographs.
- Images and Google Fonts load from the internet, so an internet connection is needed.
- The contact form currently opens the visitor's email application. It is a front-end demo;
  to collect enquiries automatically, connect Formspree, Web3Forms, or your own backend.
- Replace someboyzmedia@example.com in script.js with the studio's real email address.

NOTE
Vacancies shown are editable sample listings. Confirm current openings before publishing.
The gallery uses sample creative mood images, not verified SomeboyZ Media client work.
